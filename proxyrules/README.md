# Proxyrules

Mihomo Party 覆写 / Clash Verge Rev 扩展脚本，用于代理规则的集中管理和自定义覆写。

## 来源

本规则文件来自 [yyhhyyyyyy/selfproxy](https://github.com/yyhhyyyyyy/selfproxy)。

## 功能

`script.js` 对以下配置进行覆写：

- **基础选项**：端口、运行模式、日志级别、嗅探等
- **DNS 配置**：DNS 服务器、Fake IP 过滤、域名分流策略
- **域名规则**：国内域名直连、特定域名走代理
- **代理组**：自动选择、故障转移等策略
- **规则覆写**：IP/CIDR、域名匹配等路由规则

## 使用方式

将 `script.js` 导入到 Mihomo Party 的「覆写」功能或 Clash Verge Rev 的「扩展脚本」中使用。
